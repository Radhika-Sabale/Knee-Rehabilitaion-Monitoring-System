# 🦵 Knee Rehabilitation Monitoring System (AI-Based)


An AI-powered system for monitoring knee rehabilitation exercises using **computer vision and pose estimation**. This project helps users perform physiotherapy exercises at home with real-time feedback, improving recovery without constant supervision.


## 📌 Overview
This system uses a laptop camera and AI techniques to track body movements and analyze knee joint angles. It provides real-time feedback, repetition counting, and performance tracking for rehabilitation exercises.


## 🚀 Features
- 🎥 Real-time pose detection using MediaPipe
- 📐 Knee joint angle calculation
- 🔁 Automatic repetition counting
- 📊 Exercise quality analysis (Good/Bad reps)
- 🧍 Posture and movement tracking
- 🚶 Walking/gait analysis
- 📈 Progress visualization using graphs
- ⚠️ Safety alerts for incorrect movements
- 💾 Data storage for rehabilitation tracking


## 🛠️ Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy
- Matplotlib


## 🧠 How It Works
1. Captures live video using a webcam
2. Detects body landmarks (hip, knee, ankle)
3. Calculates knee joint angles
4. Tracks exercise states (Up, Mid, Down)
5. Counts repetitions based on movement
6. Provides real-time feedback
7. Stores and visualizes progress data


## 🏃 Supported Exercises
- Squats  
- Lunges  
- Sit-to-Stand  
- Seated Knee Extension  
- Step-up Exercises  
- Walking Tracker
